Saya mencatat kelima keputusan final tersebut sebagai **constraint implementasi yang mengikat**. Berikut ringkasan implikasi teknisnya sebelum beralih ke task baru:

| # | Keputusan | Implikasi Teknis |
|---|-----------|------------------|
| 1 | Authorization decision | Middleware baru: cek `actorId === userId` ∨ `orgId match + role=admin` ∨ `role=auditor`. Response 403 jika tidak memenuhi. |
| 2 | Reproducibility 3-field | Response `GET /api/decisions/{id}` menambahkan `historicallyReproducible`, `eligibleForNewEvaluation`, `currentPackStatus`. Logic: RETIRED → `historicallyReproducible=true`, `eligibleForNewEvaluation=false`. |
| 3 | List decision berhalaman | `GET /api/decisions` dengan pagination, filter, dan **tidak** menyertakan `evaluatedByProfile`. Hanya `evaluatedBy` (Clerk user ID) yang dikembalikan. |
| 4 | Clerk user ID sebagai text | Ubah kolom `actorId`, `verifiedBy`, `publishedBy`, `evaluatedBy` dari `uuid` menjadi `text`. Migrasi: `ALTER TABLE ... ALTER COLUMN ... TYPE text USING column::text`. |
| 5 | Audit context dalam transaksi | Middleware tidak lagi `set_config` di pool connection. Handler harus: `BEGIN` → `set_config` → mutasi → `COMMIT`. Atau gunakan `db.transaction(async tx => { await tx.execute(setAuditContextSQL); ... })`. |

Catatan untuk keputusan #4: karena data seed dan audit log lama mungkin sudah terisi dengan nilai UUID-valid, migrasi harus menggunakan `USING column::text` agar tidak gagal konversi.

## 🎯 PANDUAN DESAIN: Tampilkan Alasan Kepatuhan pada Detail Paket

### 1. Alur Pengguna (User Journey)

```
1. Pengguna membuka halaman detail paket pengadaan
2. Sistem menampilkan ringkasan paket + tombol "Evaluasi Kepatuhan"
3. Pengguna memilih policy pack yang akan digunakan (dropdown: hanya PUBLISHED)
4. Sistem mengirim POST /api/rule-evaluations dengan konteks paket
5. UI menampilkan:
   - Status evaluasi (loading → success → error)
   - Ringkasan: X aturan PASSED, Y FAILED, Z NOT_APPLICABLE
   - Daftar rule dengan penjelasan terstruktur
   - Decision reference ID dengan tombol salin
6. Jika policy pack tidak tersedia → tampilkan pesan + opsi pilih pack lain
```

```tsx
interface CompliancePanelProps {
  packageId: string;
  packageContext: PackageContext; // Nilai paket, metode, TKDN, dll
}

export function CompliancePanel({ packageId, packageContext }) {
  const [selectedPackId, setSelectedPackId] = useState<string | null>(null);
  const [evaluation, setEvaluation] = useState<EvaluationResponse | null>(null);
  const [state, setState] = useState<'idle' | 'loading' | 'success' | 'error'>('idle');
  const [error, setError] = useState<string | null>(null);

  const evaluate = async () => {
    if (!selectedPackId) return;
    setState('loading');
    setError(null);
    try {
      const result = await apiClient.postRuleEvaluations({
        packageId,
        policyPackId: selectedPackId,
        context: packageContext
      });
      setEvaluation(result);
      setState('success');
    } catch (e) {
      setError(e instanceof Error ? e.message : 'Evaluasi gagal');
      setState('error');
    }
  };

  return (
    <Card>
      <CardHeader>
        <CardTitle>Evaluasi Kepatuhan</CardTitle>
      </CardHeader>
      <CardContent className="space-y-4">
        <PolicyPackSelector
          value={selectedPackId}
          onChange={setSelectedPackId}
          disabled={state === 'loading'}
        />

        {state === 'idle' && (
          <Button onClick={evaluate} disabled={!selectedPackId}>
            Mulai Evaluasi
          </Button>
        )}

        {state === 'loading' && <EvaluationLoading />}
        {state === 'error' && <EvaluationError message={error} onRetry={evaluate} />}
        {state === 'success' && evaluation && (
          <>
            <EvaluationSummary results={evaluation.results} />
            <DecisionReferenceBadge id={evaluation.decisionReferenceId} />
            <RuleEvaluationList results={evaluation.results} />
          </>
        )}
      </CardContent>
    </Card>
  );
}
```

#### B. `PolicyPackSelector.tsx`

export function PolicyPackSelector({ value, onChange, disabled }) {
  const { data: packs, isLoading } = useQuery({
    queryKey: ['published-policy-packs'],
    queryFn: () => apiClient.getPublishedPolicyPacks()
  });

  if (isLoading) return <Skeleton className="h-10" />;

  if (!packs || packs.length === 0) {
    return (
      <Alert variant="warning">
        <AlertTitle>Tidak ada policy pack tersedia</AlertTitle>
        <AlertDescription>
          Hubungi admin hukum untuk menerbitkan policy pack terlebih dahulu.
        </AlertDescription>
      </Alert>
    );
  }

  return (
    <Select value={value} onValueChange={onChange} disabled={disabled}>
      <SelectTrigger>
        <SelectValue placeholder="Pilih policy pack..." />
      </SelectTrigger>
      <SelectContent>
        {packs.map(pack => (
          <SelectItem key={pack.id} value={pack.id}>
            {pack.packName} v{pack.version} ({pack.regimeType})
          </SelectItem>
        ))}
      </SelectContent>
    </Select>
  );
}

export function EvaluationSummary({ results }: { results: RuleEvaluationResult[] }) {
  const counts = {
    PASSED: results.filter(r => r.status === 'PASSED').length,
    FAILED: results.filter(r => r.status === 'FAILED').length,
    NOT_APPLICABLE: results.filter(r => r.status === 'NOT_APPLICABLE').length,
    ERROR: results.filter(r => r.status === 'ERROR').length,
    APPLICABLE: results.filter(r => r.status === 'APPLICABLE').length
  };

  const overallStatus = counts.FAILED > 0 || counts.ERROR > 0 
    ? 'warning' 
    : 'success';

  return (
    <div className="grid grid-cols-5 gap-2">
      <StatBadge label="Lulus" count={counts.PASSED} variant="success" />
      <StatBadge label="Gagal" count={counts.FAILED} variant="destructive" />
      <StatBadge label="Tidak Berlaku" count={counts.NOT_APPLICABLE} variant="muted" />
      <StatBadge label="Berlaku" count={counts.APPLICABLE} variant="info" />
      <StatBadge label="Error" count={counts.ERROR} variant="warning" />
    </div>
  );
}

export function ExplanationRenderer({ explanation }: { explanation: Explanation }) {
  const Template = templates[explanation.template];
  
  if (!Template) {
    // Fallback: tampilkan humanReadable jika template tidak dikenal
    return (
      <div className="text-sm text-muted-foreground">
        <p className="italic">Template tidak dikenal: <code>{explanation.template}</code></p>
        <p className="mt-1">{explanation.humanReadable}</p>
      </div>
    );
  }

  return <div className="text-sm">{Template(explanation.data)}</div>;
}

export function DecisionReferenceBadge({ id }: { id: string }) {
  const [copied, setCopied] = useState(false);

  const handleCopy = async () => {
    await navigator.clipboard.writeText(id);
    setCopied(true);
    setTimeout(() => setCopied(false), 2000);
  };

  return (
    <div className="flex items-center gap-2 p-2 bg-muted rounded">
      <span className="text-xs font-medium text-muted-foreground">Decision Reference:</span>
      <code className="text-xs font-mono flex-1 truncate">{id}</code>
      <Button 
        variant="ghost" 
        size="sm"
        onClick={handleCopy}
        aria-label="Salin decision reference"
      >
        {copied ? <CheckIcon className="h-4 w-4" /> : <CopyIcon className="h-4 w-4" />}
      </Button>
      <Button variant="outline" size="sm" asChild>
        <a href={`/decisions/${id}`} target="_blank" rel="noopener noreferrer">
          Buka Detail
        </a>
      </Button>
    </div>
  );
}

### 5. Penanganan Kasus Kritis

| Kasus | Penanganan |
|-------|------------|
| Tidak ada policy pack PUBLISHED | `PolicyPackSelector` tampilkan Alert, tombol evaluasi disabled |
| Evaluasi gagal karena konteks tidak lengkap | Tampilkan error spesifik dari API (field apa yang hilang) |
| Policy pack di-retire saat evaluasi berjalan | API return 404, UI tampilkan "Policy pack tidak lagi tersedia" |
| Decision reference gagal dibuat | API return 500, UI tampilkan error + opsi coba lagi |
| Network error | Retry button + pesan jelas |
| Rule dengan status ERROR | Tampilkan di card terpisah dengan pesan error dari formula evaluator |

### 6. Invariant yang Harus Dijaga

1. **UI tidak boleh memodifikasi aturan** — hanya membaca hasil evaluasi
2. **Decision reference ID harus ditampilkan persis seperti dari API** — jangan di-format atau di-truncate
3. **ExplanationRenderer tidak boleh render HTML mentah** — hanya template terstruktur
4. **Loading state harus jelas** — pengguna harus tahu sistem sedang bekerja
5. **Error harus actionable** — selalu sertakan tombol retry atau saran perbaikan
